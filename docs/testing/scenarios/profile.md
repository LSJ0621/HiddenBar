# 프로필 관리 E2E 시나리오

## 백엔드 API E2E

### 프로필 조회 (`GET /api/v1/users/me`)

| # | 시나리오 | 기대 결과 | 기존 커버 |
|---|---------|----------|----------|
| 1 | 이메일 유저 프로필 조회 | 200 + `{id, email, name, role, profileImage, hasPassword: true}` | ✅ |
| 2 | Google 전용 유저 프로필 조회 | 200 + `hasPassword: false` | ✅ |
| 3 | 미인증 요청 | 401 Unauthorized | ✅ |

### 프로필 수정 (`PATCH /api/v1/users/me`)

| # | 시나리오 | 기대 결과 | 기존 커버 |
|---|---------|----------|----------|
| 1 | 이름 수정 | 200 + 업데이트된 name | ✅ |
| 2 | 이름 2자 미만 (예: `A`) | 400 Bad Request | ✅ |
| 3 | 이름 30자 초과 | 400 Bad Request | ✅ |
| 4 | 미인증 요청 | 401 Unauthorized | ✅ |

### 비밀번호 변경 (`PATCH /api/v1/users/me/password`)

| # | 시나리오 | 기대 결과 | 기존 커버 |
|---|---------|----------|----------|
| 1 | 올바른 현재 비밀번호 + 유효한 새 비밀번호 | 204 No Content | ✅ |
| 2 | 잘못된 현재 비밀번호 | 401 Unauthorized | ✅ |
| 3 | 새 비밀번호 8자 미만 | 400 Bad Request | ✅ |
| 4 | 새 비밀번호 숫자 미포함 | 400 Bad Request | ✅ |
| 5 | 현재 비밀번호와 동일한 새 비밀번호 | 400 Bad Request | ✅ |
| 6 | 소셜 전용 계정 (비밀번호 없음) 비밀번호 변경 | 403 Forbidden | ✅ |
| 7 | 변경 후 새 비밀번호로 로그인 | 200 (로그인 성공) | ✅ |
| 8 | 변경 후 기존 비밀번호로 로그인 | 401 (로그인 실패) | ✅ |

### 프로필 이미지 업로드 (`POST /api/v1/users/me/profile-image`)

| # | 시나리오 | 기대 결과 | 기존 커버 |
|---|---------|----------|----------|
| 1 | JPEG 이미지 업로드 | 200 + profileImage URL 반환 | ✅ |
| 2 | PNG 이미지 업로드 | 200 + profileImage URL 반환 | ✅ |
| 3 | 유효하지 않은 파일 타입 (txt) | 400 Bad Request | ✅ |
| 4 | 파일 크기 초과 (>5MB) | 413 Payload Too Large | ✅ |
| 5 | 파일 미첨부 | 400 Bad Request | ✅ |
| 6 | 이미지 교체: 기존 이미지가 있는 유저 재업로드 | 200 + 새 profileImage URL (기존 대체) | ✅ |
| 7 | 미인증 요청 | 401 Unauthorized | ✅ |

## 프론트엔드 브라우저 E2E

### 프로필 페이지 (`/profile`)

| # | 시나리오 | 검증 항목 |
|---|---------|----------|
| 1 | 프로필 정보 표시 | `profile-name` (이름), `profile-email` (이메일), 역할 배지 노출 |
| 2 | 프로필 이미지 | 프로필 이미지 또는 기본 아바타 표시 |
| 3 | 수정 버튼 | `profile-edit-button` 클릭 → `/profile/edit` 이동 |
| 4 | 미인증 접근 | `/profile` → `/login` 리다이렉트 |

### 프로필 수정 페이지 (`/profile/edit`)

| # | 시나리오 | 검증 항목 |
|---|---------|----------|
| 1 | 기존 정보 로드 | `profile-name-input`에 현재 이름 채워짐 |
| 2 | 이름 수정 | 이름 변경 → `profile-save-button` 클릭 → `/profile`에서 업데이트 확인 |
| 3 | 유효하지 않은 이름 | 1자 입력 → 인라인 에러 |
| 4 | 뒤로가기 | `profile-back-button` 클릭 → `/profile` 이동 |

### 프로필 이미지

| # | 시나리오 | 검증 항목 |
|---|---------|----------|
| 1 | 이미지 업로드 | `profile-image-uploader` 클릭 → 파일 선택 → 미리보기 표시 |
| 2 | 저장 후 반영 | 저장 → 프로필 페이지에 새 이미지 표시 |

### 비밀번호 변경 섹션

| # | 시나리오 | 검증 항목 |
|---|---------|----------|
| 1 | 이메일 유저 | `password-current-input`, `password-new-input`, `password-confirm-input`, `password-change-button` 노출 |
| 2 | 소셜 유저 | 비밀번호 변경 섹션 숨김 |
| 3 | 성공 | 올바른 현재/새/확인 입력 → 제출 → 성공 토스트 + 폼 초기화 |
| 4 | 현재 비밀번호 틀림 | 에러 메시지 표시 |
| 5 | 짧은 비밀번호 | 인라인 에러 |
| 6 | 확인 불일치 | 새 비밀번호 ≠ 확인 → 인라인 에러 |
| 7 | 로딩 | 제출 시 버튼 disabled + 스피너 |
