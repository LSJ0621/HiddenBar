# 검색 & 필터 E2E 시나리오

## 백엔드 API E2E (`GET /api/v1/bars/search`)

인증 전제: 홈 화면 `/`만 공개이며, 검색 API는 로그인한 사용자 기준으로 검증한다.

### 이름 검색

| #   | 시나리오                        | 기대 결과                           | 커버 |
| --- | --------------------------- | ------------------------------- | --- |
| 1   | `?name=cocktail` — 이름에 매칭되는 바 | 200 + 이름 후보 목록 반환 | ✅ |
| 2   | `?name=secret&userLat=13.75&userLng=100.50` | 200 + 가까운 후보 우선 정렬 | ✅ |
| 3   | `?name=zzznotexist` — 매칭 없음 | 200 + items: [] | ✅ |
| 4   | PENDING/REJECTED 바 미포함 확인 | APPROVED 바만 검색 결과에 포함 | ✅ |
| 5   | 미인증 요청 | 401 Unauthorized | ✅ |

### 일반 목록 / 위치 검색

| #   | 시나리오 | 기대 결과 | 커버 |
| --- | --- | --- | --- |
| 1   | 파라미터 없음 | 200 + 기본 목록 반환 | ✅ |
| 2   | `?lat=37.50&lng=127.02` | 200 + 해당 좌표 근처 바 반환 | ✅ |
| 3   | `?name=bar&lat=37.50&lng=127.02` | 200 + 해당 위치 근처 이름 후보 반환 | ✅ |
| 4   | `?lat=37.50` | 400 Bad Request | ✅ |

### 정렬

| #   | 시나리오                      | 기대 결과                          | 커버 |
| --- | ------------------------- | ------------------------------ | --- |
| 1   | `?sortBy=newest`          | createdAt DESC 정렬              | ✅ |
| 2   | `?sortBy=bookmarks`       | 북마크 수 DESC 정렬                  | ✅ |
| 3   | `?name=bar&userLat=37.50&userLng=127.02` | 거리 보조 정렬 적용 | ✅ |

### 페이지네이션

| #   | 시나리오                        | 기대 결과                                    | 커버 |
| --- | --------------------------- | ---------------------------------------- | --- |
| 1   | `?offset=0&limit=5`         | 5개 이하 반환 + hasMore (6번째 존재 여부로 판단)       | ✅ |
| 2   | `?offset=5&limit=5`         | 다음 5개 반환 + hasMore 정확                    | ✅ |
| 3   | hasMore=false인 경우           | 더 이상 데이터 없음을 의미 (offset+limit >= 전체 개수)  | ✅ |
| 4   | 전체 데이터보다 큰 offset           | 200 + items: [] + hasMore: false          | ✅ |

## 프론트엔드 브라우저 E2E

### 검색 페이지 (`/search`)


| #   | 시나리오      | 검증 항목                                        | 상태 |
| --- | --------- | -------------------------------------------- | --- |
| 1   | 미인증 접근 | `/login` 리다이렉트 | ✅ |
| 2   | 인증 후 이름 검색 결과 | `search-input`에 입력 → `bar-card-{id}` 목록 업데이트 | ✅ |
| 3   | 바 카드 정보   | 이름, 도시, 썸네일 표시                                | ✅ |
| 4   | 바 카드 클릭   | `/bars/[id]`로 이동                             | ✅ |


### 탭 기반 검색

> 검색바는 4개 탭으로 구성: Address(주소) / Name(이름) / Both(주소+이름) / Map Pin(지도 핀).

| #   | 시나리오          | 검증 항목                                                                    | 상태 |
| --- | ------------- | ------------------------------------------------------------------------ | --- |
| 1   | Address 탭     | `address-search-input` 노출, 주소 검색 → `address-dropdown` 자동완성 결과 → 선택 시 검색 | ✅ |
| 2   | Name 탭        | `search-input` + `search-button` 노출, 이름 입력 → `bar-name-dropdown` 자동 제안  | ✅ |
| 3   | Both 탭        | 주소 + 이름 입력 필드 모두 노출, 주소 선택 후 이름 입력 가능                                   | ✅ |
| 4   | Map Pin 탭     | 지도 노출, 지도 클릭 → 핀 생성 → "Search here" 버튼 클릭 시 해당 좌표 근처 검색                | ✅ |
| 5   | 이름 자동 제안 선택   | `bar-name-dropdown` 항목 클릭 → `/bars/[id]` 상세 페이지 이동                      | ✅ |
| 6   | 탭 변경 → URL 동기화 | 탭 전환 시 URL 파라미터 `tab` 값 업데이트                                           | ✅ |


### 더보기 (Load More)


| #   | 시나리오        | 검증 항목                                                   | 상태 |
| --- | ----------- | ------------------------------------------------------- | --- |
| 1   | 추가 결과 있음    | `load-more-button` 표시, 클릭 → 추가 결과 append                | ✅ |
| 2   | 추가 결과 없음    | `load-more-button` 미표시 (hasMore: false)                  | ✅ |
| 3   | 로딩 중        | `load-more-button` disabled + "Loading..." 텍스트           | ✅ |


### 빈 결과


| #   | 시나리오     | 검증 항목                   | 상태 |
| --- | -------- | ----------------------- | --- |
| 1   | 매칭 없는 검색 | `search-empty-state` 표시 | ✅ |


### URL 상태 관리


| #   | 시나리오      | 검증 항목                                              | 상태 |
| --- | --------- | -------------------------------------------------- | --- |
| 1   | 필터 → 새로고침 | 필터 적용 상태에서 새로고침 → 필터 보존                            | ✅ |
| 2   | 뒤로가기      | 검색 → 결과 클릭 → 뒤로 → 이전 검색 상태(검색어, 필터, 페이지) 복원        | ✅ |
| 3   | URL 직접 입력 | `/search?name=bar` → 필터 반영된 결과 | ✅ |


### 북마크 토글 (검색 결과)


| #   | 시나리오   | 검증 항목                                        | 상태 |
| --- | ------ | -------------------------------------------- | --- |
| 1   | 인증 유저  | `bar-card-bookmark-{id}` 클릭 → 아이콘 토글 (옵티미스틱) | ✅ |
| 2   | 미인증 유저 | 북마크 클릭 → `/login` 리다이렉트                      | ✅ |
